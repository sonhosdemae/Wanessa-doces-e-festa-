    🎥 VÍDEO TUTORIAL - PUBLICAR SITE EM 3 MINUTOS

    📍 CENA 1 - SALVANDO O ARQUIVO (0:00 - 0:45)

    NARRAÇÃO: "Olá! Vou te mostrar como colocar a Loja Sonhos de Mãe no ar em 3 minutos. Primeiro, vamos salvar o código..."

    AÇÕES:

    1. ✅ Abra o Bloco de Notas (Windows) ou TextEdit (Mac)

      • Windows: Aperte Win + R, digite notepad e Enter
      • Mac: Procure por TextEdit no Spotlight

    2. ✅ COPIE TODO O CÓDIGO que enviei (role até o início da conversa)

    3. ✅ COLE no Bloco de Notas (Ctrl+V ou Cmd+V)

    4. ✅ Clique em Arquivo → Salvar Como

    5. ✅ IMPORTANTE:

      • Nome do arquivo: index.html
      • Tipo: Todos os Arquivos (não deixe .txt)
      • Salve na Área de Trabalho

    📍 CENA 2 - TESTANDO LOCALMENTE (0:45 - 1:30)

    NARRAÇÃO: "Agora vamos testar se está funcionando..."

    AÇÕES:

    1. ✅ Vá até sua Área de Trabalho
    2. ✅ Dê dois cliques no arquivo index.html
    3. ✅ O site abrirá no navegador!

    TESTE ESTAS FUNÇÕES:

    • 🛒 Clique em "Adicionar ao Carrinho" em algum produto
    • 👀 Veja o número aumentar no ícone do carrinho (canto superior direito)
    • 🔍 Clique no ícone do carrinho para ver os itens
    • ➕➖ Teste aumentar/diminuir quantidade
    • 💬 Clique no botão verde de WhatsApp (canto inferior direito)

    📍 CENA 3 - PUBLICANDO GRÁTIS (1:30 - 3:00)

    NARRAÇÃO: "Agora vamos colocar no ar para o mundo todo ver!"

    MÉTODO 1 - NETLIFY (MAIS FÁCIL):

    1. ✅ Acesse: https://app.netlify.com/drop

    2. ✅ Você verá uma área escrito "Drop your site here"

    3. ✅ ARRASTE o arquivo index.html da Área de Trabalho para dentro da página

    4. ✅ PRONTO! Em 10 segundos aparecerá:

      • ✨ Seu site publicado!
      • 🔗 Um link tipo: https://glowing-cupcake-123abc.netlify.app

    5. ✅ COPIE ESSE LINK e compartilhe nas redes sociais!

    🆘 PROBLEMAS COMUNS E SOLUÇÕES

    ❌ "Abre como texto, não como site"

    SOLUÇÃO: Você salvou como .txt em vez de .html

    • Renomeie o arquivo: clique direito → Renomear → mude para index.html

    ❌ "Netlify não aceita o arquivo"

    SOLUÇÃO:

    • Certifique-se que o arquivo se chama exatamente index.html
    • Tente o site alternativo: https://tiiny.host

    SOLUÇÃO:

    • Verifique se copiou o código completo (incluindo a parte <script>)

        // SISTEMA DE CARRINHO
        let carrinho = JSON.parse(localStorage.getItem('carrinho')) || [];

        function atualizarCarrinho() {
            // Atualizar contador
            document.getElementById('carrinho-count').textContent = carrinho.reduce((total, item) => total + item.quantidade, 0);
            
            // Atualizar lista de itens
            const container = document.getElementById('itens-carrinho');
            
            if (carrinho.length === 0) {
                container.innerHTML = `
                    <div class="carrinho-vazio">
                        <div class="icone">🛒</div>
                        <h3>Seu carrinho está vazio</h3>
                        <p>Adicione produtos para começar!</p>
                    </div>
                `;
                document.getElementById('total-carrinho').innerHTML = '';
                return;
            }
            
            container.innerHTML = carrinho.map((item, index) => `
                <div class="item-carrinho">
                    <img src="${item.imagem}" alt="${item.nome}">
                    <div class="item-info">
                        <h4>${item.nome}</h4>
                        <div class="preco">R$ ${item.preco.toFixed(2)}</div>
                    </div>
                    <div class="item-acoes">
                        <button class="btn-quantidade" onclick="alterarQuantidade(${index}, -1)">-</button>
                        <span class="quantidade">${item.quantidade}</span>
                        <button class="btn-quantidade" onclick="alterarQuantidade(${index}, 1)">+</button>
                        <button class="btn-remover" onclick="removerItem(${index})">🗑️</button>
                    </div>
                </div>
            `).join('');
            
            // Calcular total
            const subtotal = carrinho.reduce((total, item) => total + (item.preco * item.quantidade), 0);
            
            document.getElementById('total-carrinho').innerHTML = `
                <div class="total-carrinho">
                    <div class="linha">
                        <span>Subtotal:</span>
                        <span>R$ ${subtotal.toFixed(2)}</span>
                    </div>
                    <div class="linha total">
                        <span>Total:</span>
                        <span>R$ ${subtotal.toFixed(2)}</span>
                    </div>
                </div>
            `;
            
            localStorage.setItem('carrinho', JSON.stringify(carrinho));
        }

        function adicionarAoCarrinho(nome, preco, imagem) {
            const itemExistente = carrinho.find(item => item.nome === nome);
            
            if (itemExistente) {
                itemExistente.quantidade++;
            } else {
                carrinho.push({
                    nome: nome,
                    preco: preco,
                    imagem: imagem,
                    quantidade: 1
                });
            }
            
            atualizarCarrinho();
            
            // Animação de confirmação
            const btn = event.target;
            const textoOriginal = btn.textContent;
            btn.textContent = '✓ Adicionado!';
            btn.style.backgroundColor = '#4CAF50';
            
            setTimeout(() => {
                btn.textContent = textoOriginal;
                btn.style.backgroundColor = '';
            }, 1500);
        }

        function alterarQuantidade(index, mudanca) {
            carrinho[index].quantidade += mudanca;
            
            if (carrinho[index].quantidade <= 0) {
                carrinho.splice(index, 1);
            }
            
            atualizarCarrinho();
        }

        function removerItem(index) {
            if (confirm('Deseja remover este item do carrinho?')) {
                carrinho.splice(index, 1);
                atualizarCarrinho();
            }
        }

        function abrirCarrinho() {
            document.getElementById('modalCarrinho').classList.add('ativo');
        }

        function fecharCarrinho() {
            document.getElementById('modalCarrinho').classList.remove('ativo');
        }

        // Fechar modal ao clicar fora
        document.getElementById('modalCarrinho').addEventListener('click', function(e) {
            if (e.target === this) {
                fecharCarrinho();
            }
        });

        function finalizarPedido() {
            if (carrinho.length === 0) {
                alert('Seu carrinho está vazio!');
                return;
            }
            
            let mensagem = '🎉 *Olá! Gostaria de fazer um pedido:*\n\n';

                mensagem += `Subtotal: R$ ${(item.preco * item.quantidade).toFixed(2)}\n\n`;
            });
            
            const total = carrinho.reduce((sum, item) => sum + (item.preco * item.quantidade), 0);
            mensagem += `*TOTAL: R$ ${total.toFixed(2)}*\n\n`;
